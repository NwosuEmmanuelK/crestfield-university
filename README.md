# Crestfield University Website

A responsive multi-page university website built with React, Vite, React Router and CSS. Crestfield University is a fictional Nigerian private university created for an individual React JS practical project.

## Features
- Home, About, Faculties & Courses, Admissions and Contact pages
- Responsive navigation menu
- Reusable React components and data-driven course cards using `.map()`
- Course search
- Controlled admission and contact forms with validation and feedback
- React Router navigation
- Responsive layouts for mobile, tablet and desktop

## Technologies
- React JS
- Vite
- JavaScript / JSX
- React Router DOM
- Lucide React icons
- CSS

## Installation
1. Install Node.js.
2. Open this folder in Visual Studio Code.
3. Open the terminal in the project folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed in the terminal (usually http://localhost:5173).

## Production build
Run `npm run build`. The generated website will be in the `dist` folder.

## Deployment
You can import this GitHub repository into Vercel or Netlify. Use `npm run build` as the build command and `dist` as the output directory.

## Note
Crestfield University and its contact details are fictional sample content for this educational project. Form submissions are validated in the browser and display a demo confirmation; they are not sent to a real university server.
